Windows installation guide

Start OpsNest in one calm, clear setup.

The installer contains the desktop application. Your invoice template and local data stay on the computer you choose for your work.

Install OpsNest

  1. Download the current installer.
    Use the button below to download OpsNest-Setup-2.9.5.exe.
  2. Open the downloaded file.
    If Windows asks for permission, confirm that you want to run the OpsNest installer.
  3. Choose the suggested installation location.
    The setup creates the application folder, desktop shortcut and Start menu shortcut if selected.
  4. Open OpsNest.
    On the first screen choose your working language and register your company. Your seven-day trial begins immediately at this step.
  5. Complete company details, then create a project.
    Add your VAT number, bank data and logo. These become available for new invoices automatically.

First five actions inside the app

  1. Add a customer if you already know who will receive an invoice.
  2. Create a project and set its invoice number block.
  3. Import an incoming PDF bill or add a cost manually.
  4. Create the first invoice from the project dashboard.
  5. Record payments as they arrive.

Updating OpsNest

Use Plans and billing > Check updates in the app. If a new version is available, download the installer, close OpsNest and run the update. Your local data is not removed by an update.

Ready to install?

Download the Windows installer. The trial needs no card and starts when your company is registered.
